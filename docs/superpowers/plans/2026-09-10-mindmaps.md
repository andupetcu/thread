# Mind maps implementation plan

User request: add easy visual idea capture as mind maps, referencing notes and OKF content; choose a suitable open-source framework. This extends the in-flight diagram upgrade. Existing diagram work remains required.

Design: a dedicated `thread-mindmap` Markdown block and focused full-screen editor, using the already-installed React Flow engine (official mind-map tutorial: https://reactflow.dev/learn/tutorials/mind-map-app-with-react-flow). A tree-specific model provides faster authoring than a generic diagram canvas. No new framework dependency or database table. Native note storage, sharing, revisions and backups remain authoritative.

Ruling: user explicitly delegates implementation/framework choices; proceed with this concrete design under that authorization, without another approval round. No commit/push requested.

## Contract

`src/mindmap/model.js` exports:
- `parseMindMap(value)` canonical `{version:1,rootId,layout:'both'|'right',nodes:[{id,parentId?,label,color?,collapsed?,side?:'left'|'right',link?}]}`. Exactly one root, unique IDs, connected acyclic tree, at most300nodes and1MBJSON, labels max500. Root has no parent. Nonroot parent required. No raw positions; layout derived deterministically. `side` meaningful on root children, descendants inherit branch side.
- Links: existing diagram note/block/concept/url/asset shapes plus `{kind:'bundle',bundleId}`. Reuse validation where practical. No executable URLs.
- `defaultMindMap()` creates a single root label `Central idea`.
- `layoutMindMap(value,{includeCollapsed=false}={})` returns v2 diagram-shaped nodes+edges with deterministic absolute positions, dimensions, branch colors. Balanced left/right or all-right tree, hide descendants of collapsed nodes without deleting them. Source remains a semantic tree. Non-diagram bundle link omitted from projection; UI uses original node link.
- `addIdea(value,parentId,label='New idea',options?)`, `addSibling(value,nodeId,label='New idea')`, `removeBranch(value,nodeId)` (root retained), `reparentIdea(value,nodeId,parentId)` (prevent cycles), `updateIdea(value,nodeId,patch)`; immutable canonical operations. New nodes append ordered. `duplicateBranch` remaps IDs/links and retains subtree. `mindMapToOutline(value)` and `outlineToMindMap(text)` for Markdown bullets/indentation, bounded nesting; preserve complete tree on export.
- `mindMapToSvg(value,options)` delegates existing shared SVG renderer over layout; links use safe projection. No image uploads needed for initial mind maps, but document/asset links supported.

`MindMapBlock.jsx` props: `{value,onChange,readOnly=false,context,recoveryKey}`. Same context as DiagramBlock plus `onOpenBundle(bundleId)`. It validates/previews, displays accessible link actions, opens fullscreen editor. Save passes serialized native mind map (not diagram projection). Context retainRecoveryOnSave controls nested OKF saving; ordinary saves await onChange before clearing. Recovery key namespace `thread-mindmap-draft:`; keep viewport separate. Explicit Save/discard and crash recovery. Do not borrow generic diagram editing behavior that lets users break tree semantics.

Editor: click/double-click ideas to edit, Enter adds sibling, Tab adds child (outside text fields), buttons for the same actions, collapse/expand, branch color, both/right layout, delete/duplicate branch, drag an idea onto another to reparent with cycle validation, explicit parent selector fallback, zoom/fit/minimap, undo/redo. Start selected root. Native note/block/OKF concept/bundle/URL link picker and Open target. Import indented outline with preview/explicit replacement; export Markdown outline, native JSON and SVG/PNG. Local storage only. Shared root draft and note navigation policies apply.
